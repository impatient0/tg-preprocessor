# tg-preprocessor

Превращает экспорт чата из Telegram Desktop (`result.json`) в компактный текст для загрузки в LLM
(анализ переписки, саммари и т.п.). Один файл, только стандартная библиотека, Python 3.9+.

```
python tg_preprocess.py result.json
```

Результат по умолчанию — `<название чата>.txt` рядом с входным файлом. В статистике (stderr) видно,
во сколько раз сжалось и сколько примерно токенов получилось.

## Что получается на выходе

```
Чат «Рабочая группа» — группа, участников: 3
Период: 2026-09-01 — 2026-09-25, сообщений: 168
Участники: Анна, Борис, Вика

=== 2026-09-04 (пт) ===
Анна [16:02]: [Файл: отчёт.pdf] Добрый день! Вот отчёт за неделю
Вот таблица для записи: [ссылка: docs.google.com]
Борис [16:10]: [↪ Анна: «Добрый день! Вот отчёт за неделю Вот таблица…»] Спасибо, посмотрим
Вика [16:12]: [Голосовое 0:12] <👍 Борис>
```

(вторая строка Анны — это второе сообщение того же блока; реакции видны только с `--reactions`)

- заголовок дня вместо даты в каждой строке;
- подряд идущие сообщения одного автора склеиваются в блок (по умолчанию — в пределах 5 минут);
- ответ — короткая цитата в квадратных скобках, обрезанная по границе слова;
- медиа заменяются краткими пометками: `[Фото]`, `[Файл: имя.pdf]`, `[Голосовое 0:12]`, `[Стикер 😀]`, `[Опрос «…»: вариант | вариант]`;
- «изменено», ID сообщений, ID пользователей и прочая служебка не выводятся.

## Опции

| Опция | По умолчанию | Что делает |
|---|---|---|
| `-o, --output ПУТЬ` | рядом с входным | Куда писать. `-o -` — в stdout (только без разбивки на части) |
| `--reactions` | выкл. | Добавлять реакции: `<👍 Ivan>`, `<🔥×5>` (имена — если реакций ≤ 3) |
| `--links {domain,keep,drop}` | `domain` | Ссылки: заменять на `[ссылка: домен]`, оставлять как есть или убирать |
| `--keep-service` | выкл. | Оставлять служебные сообщения (вступление, закрепы и т.п.). Звонки остаются всегда |
| `--no-media` | выкл. | Не выводить пометки о медиа; сообщения только из медиа пропускаются |
| `--merge-window МИН` | `5` | Склеивать сообщения одного автора, если между ними не больше N минут (`0` — только в одну минуту) |
| `--quote-min`, `--quote-max` | `30`, `60` | Диапазон длины цитаты ответа в символах; режется по целому слову |
| `--quote-adjacent` | выкл. | Цитировать и ответ на сообщение, стоящее строкой выше (по умолчанию цитата опускается — она ничего не добавляет) |
| `--short-names` | выкл. | Только имя без фамилии, если оно однозначно |
| `--since ДАТА`, `--until ДАТА` | — | Ограничить период (`ГГГГ-ММ-ДД`, включительно) |
| `--max-tokens N` | без лимита | Разбить на части ≈ по N токенов (файлы `имя_001.txt`, `имя_002.txt`…) |
| `--no-header` | выкл. | Не писать шапку с названием чата и участниками |
| `--chat`, `--list-chats` | — | Для экспорта всех чатов сразу: показать список / выбрать чат (номер, id или часть названия) |

## Заметки

- **Оценка токенов приблизительная** (эвристика по числу символов, отдельно для кириллицы и латиницы), реальный
  токенизатор у разных моделей свой. При `--max-tokens` заложено ~10% запаса. Режет по границам дней, а если день
  сам не помещается — по границам блоков; в начале каждой части повторяется шапка и заголовок дня.
- Один и тот же человек в экспорте может называться по-разному (в сообщениях и в реакциях) — имена
  сводятся по ID пользователя. Символы «зачёркивания» в никах вычищаются.
- Ответ на сообщение, которого нет в выгрузке, помечается `[↪ сообщение вне выгрузки]`.
- Проверялось на личном чате и на группе (супергруппа). Форумные темы, каналы, звонки и редкие типы
  медиа (геолокация, контакты, игры) обработаны по документации формата, но на реальных данных не проверялись.
